# 已停用的脚本（仅存档，勿使用）

自 2026-11-10 起，本 skill 的登录环节**只允许人工手动完成**。以下脚本已从工作目录移出并停用：

| 文件 | 原作用 | 停用原因 |
|---|---|---|
| `mtrj_login_auto.js` | 半自动登录：自动过 WAF 滑块 + 自动填账号密码，仅验证码需人工 | 用户要求撤销一切自动过验证、自动填表能力 |
| `mtrj_guard.js` | WAF「旋转拼图」滑块自动求解 | 同上，滑块必须由真人手动拖动 |
| `guard_solve_pos.py` | 为滑块求解做图像定位 | 同上 |

**现行唯一登录方式**：`scripts/mtrj_login.js`（打开可见浏览器 → 人手动过滑块、人工输入账号密码与验证码 → 脚本只轮询登录状态并导出 `storage-state.json`）。

**不要**：
- 不要在 `mtrj_publish.js` 或任何流程里恢复自动过滑块 / 自动填表逻辑；
- 不要读取 `~/.mtrj/cred.json` 等任何凭据文件来自动登录；
- 不要依赖 `~/.mtrj/ensure_login.js`（旧版自动续登脚本，已与当前 skill 脱钩）。

如未来确实需要恢复自动化登录，须由用户明确书面要求后再改。
